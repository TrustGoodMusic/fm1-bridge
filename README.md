FM-1 Bridge

The FM-1 Firmware Ecosystem for openDAW

FM-1 Bridge is an open-source initiative to bring M-VAVE FM-1 synthesizer instruments and compatible firmware projects into openDAW through WebCLAP.

Vision

The FM-1 community has created a growing ecosystem of alternative synthesizer firmwares and instruments.

Our goal is to make these instruments accessible directly inside modern browser-based digital audio workstations.

Project Goals
Explore VIBE FM as a potential audio engine.
Develop a WebCLAP integration for openDAW.
Support multiple compatible FM-1 instruments and firmwares.
Provide MIDI support and parameter automation.
Make installation and usage accessible to musicians.
Encourage collaboration between firmware developers and the openDAW community.
Development Status

Phase 1 – Research and feasibility

We are currently investigating existing FM-1 firmware projects, VIBE FM, and the openDAW WebCLAP interface.

No working integration is available yet.

Community

This project aims to connect FM-1 firmware developers, musicians, and openDAW contributors.

Contributions and technical discussions are welcome.
